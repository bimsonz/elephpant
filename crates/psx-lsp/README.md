# psx-lsp

Language Server Protocol implementation for PHPScript (`.psx`). Provides diagnostics, hover info, goto definition, and document/workspace symbols to any LSP-aware editor.

The companion VS Code extension lives at [`editors/vscode/`](../../editors/vscode/) in the parent repo.

Part of the [PHPScript](https://github.com/bimsonz/elephpant) compiler workspace.
