# psx-emitter

TypeScript-source emitter for PHPScript (`.psx`). Walks a [`psx-ast`](https://crates.io/crates/psx-ast) `Module` and produces clean TypeScript source. No runtime library — every PHPScript construct lowers to native JS/TS.

Part of the [PHPScript](https://github.com/bimsonz/elephpant) compiler workspace.
