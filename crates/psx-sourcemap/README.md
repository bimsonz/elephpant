# psx-sourcemap

Source-map-v3 builder for PHPScript (`.psx`). Produces the `.ts.map` files that pair with each emitted `.ts`, so chained source maps (`.js` → `.ts` → `.psx`) resolve back to the original PHPScript line in debuggers and stack traces.

Part of the [PHPScript](https://github.com/bimsonz/elephpant) compiler workspace.
