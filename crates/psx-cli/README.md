# psx-cli — the `psx` binary

PHPScript (`.psx`) compiler — PHP-flavored TypeScript. See the [PHPScript repo](https://github.com/bimsonz/elephpant) for full documentation and examples.

```bash
psx build path/to/file.psx       # single file
psx build path/to/project/       # walks a directory
psx build                        # looks for psx.json and compiles a project
```
